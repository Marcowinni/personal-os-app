Datenschutzerklärung

Personal OS ist eine private Anwendung von Marco Winistörfer, Schweiz. Einziger Nutzer ist der Eigentümer selbst.

Welche Daten verwendet werden

  • Google Kalender: Termine lesen sowie eigene Termine eintragen und verschieben.
  • Gmail: ausgewählte Mails nur lesen. Die Anwendung sendet, ändert oder löscht keine Mails.

Wo die Daten liegen

Die Daten werden auf einem privaten Server in der Schweiz gespeichert und nur für die persönliche Organisation des Eigentümers verwendet. Zur Verarbeitung eigener Anfragen kann ein KI-Dienst eingesetzt werden. Die Daten werden nicht verkauft, nicht für Werbung verwendet und nicht an andere weitergegeben.

Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen, die über Google APIs empfangen werden, hält sich an die Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
